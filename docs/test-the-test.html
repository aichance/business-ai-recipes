What this does — and its limits

This page runs a small browser harness, not the Node CLI. It saves English in a synthetic iframe, records the baseline, performs a real iframe reload and reads the result. The fixture is byte-identical to the published single-text example.

The count implementation here is scoped to that fixture's heading: a non-empty box and CSS visibility. It is not a general replacement for Playwright locators. Text is read from a leaf with no hidden children; no pixel, occlusion, screen-reader or translation-quality test is made.

Only the fixture's example-single-language storage key is temporarily used; its previous value is restored after a run. No app URL, account, API key or user data is requested. Blocked storage or a missing baseline produces an error instead of a PASS. Do not run the same synthetic fixture concurrently in another tab.

These faults are authored examples. A reader's feedback prompted the count-only counterexample. Browser runs on this page are not counted as independent own-app adoption.
