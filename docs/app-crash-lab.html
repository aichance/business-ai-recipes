Install with the Skills CLI

With Node 22.20+, open your app project's directory and review the skill source. If .agents/skills/app-crash-lab already exists, keep and review that folder instead of installing over it.

npx --yes skills@1.7.2 add https://github.com/aichance/business-ai-recipes --skill app-crash-lab --agent codex --copy --yes --json

This copies the four skill files into this project's .agents/skills/app-crash-lab and adds skills-lock.json. The installer also keeps its own user-level metadata. We verified the installer command on macOS with Node 24.19.0 and Skills CLI 1.7.2. The v0.2.2 ZIP is checked separately against all four source files. Installing instructions alone does not run a test.
